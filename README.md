# listam

Telegram-бот, который следит за поисками на list.am и присылает алерты:
🆕 новое объявление · 📉📈 изменилась цена · ✏️ изменилось описание.

## Источники

| | list.am | banali.am |
|---|---|---|
| Доступ | HTTP-клиент с отпечатком Chrome (`curl_cffi`) и повторами; запасной режим: Chromium под Xvfb | обычный JSON API |
| Фильтры | в ссылке (`n=`, `price2=`, `srt=0`) | в коде (`sources.py`): аренда, помесячно, квартиры, Ереван, 8 районов по `govId` |
| Цена | в ссылке | проверяется в коде (доллары переводятся по курсу banali) |
| Обновление | `Renewed` на странице объявления + «перескок» в выдаче | `updatedToTop` прямо в выдаче |

Автоподнятия на banali (ежедневный пакет 00:00–00:05 UTC, раз в 3 дня на объявление) не считаются
обновлением: алерта «Renewed» на них нет. Цена и описание по ним по-прежнему отслеживаются.
Отключить banali: `BANALI=0` в `.env`.

## Как это работает

- list.am за Cloudflare. По умолчанию используется лёгкий HTTP-клиент с отпечатком Chrome: треть запросов
  получает проверку, но проходит с повтора (до 6 попыток). Это ~170 МБ памяти вместо 1–2 ГБ.
  Запасной режим `LISTAM_FETCHER=browser` (образ `Dockerfile.browser`): Chromium с окном под Xvfb.
- Поиск зашит в `listam/config.py`: долгосрочная аренда квартир (категория 56), Ереван без Авана,
  Нор-Норка, Нор-Мараша и Нубарашена, цена до 220 000 ֏, сортировка по умолчанию `srt=0` (по времени последнего обновления: максимум из даты публикации и обновления; `srt=3` «по дате» обновления не видит). Районы заданы
  списком `n=2,3,5,6,7,8,9,13`; на случай сбоя фильтра есть вторая проверка по названию района.
  Другой поиск можно задать переменной `SEARCH_URL` (скопировав ссылку с list.am).
  Если поменять URL, бот заново сохранит базу молча.
- Раз в `POLL_INTERVAL` секунд бот открывает первую страницу каждого поиска и сравнивает её с SQLite.
- Описание в выдаче не показывается, поэтому для новых объявлений и по кругу (по `DESC_CHECKS_PER_CYCLE`
  за цикл) открываются страницы самих объявлений.
- Первый проход нового поиска сохраняет базу молча, чтобы не получить 100 алертов сразу.
- При блокировке Cloudflare бот пишет «blocked» (один раз) и «reachable again», когда доступ вернулся.

## Деплой на VPS

```bash
git clone <repo> listam && cd listam      # или scp папки
cp .env.example .env && nano .env         # BOT_TOKEN, ALLOWED_CHAT_IDS
docker compose up -d --build
docker compose logs -f
```

Нужно: Docker, 1 vCPU / 2 GB RAM (Chromium прожорлив), около 1 ГБ диска.
`ALLOWED_CHAT_IDS` — ваш Telegram id (напишите боту `/start`, он ответит вашим id).

## Команды бота

`/start` — показывает ваш chat id · `/status` — что отслеживается и сколько объявлений в базе.

## Если Cloudflare блокирует VPS

IP дата-центров проверяются строже домашних. Варианты по возрастанию усилий:
1. Подождать и посмотреть логи: проверка часто проходит на второй-третьей попытке.
2. Задать `PROXY_URL` с резидентным/мобильным прокси.
3. Другой VPS-провайдер или регион (Армения/Грузия/ЕС часто проходят лучше).

## Hugging Face Space (Gradio SDK): бесплатно, с настоящим браузером

Почему не Render и не лёгкий режим: с IP дата-центров Cloudflare отклоняет лёгкий HTTP-клиент
(на раннере GitHub 12 из 12 запросов получили 403), а настоящий Chromium проходит проверку
(3 из 3, за 2–3 секунды). Браузеру нужна память, которой нет у бесплатного Render (512 МБ), а у
бесплатного Space 2 vCPU и 16 ГБ.

Файлы Space лежат в `space/`: `app.py` (бот в фоне + `/health` + страница-заглушка Gradio),
`requirements.txt`, `packages.txt` (системные библиотеки Chromium и Xvfb).

1. huggingface.co → New Space: SDK **Gradio**, шаблон Blank, CPU basic.
2. Space → Settings → Variables and secrets: секреты `BOT_TOKEN`, `ALLOWED_CHAT_IDS`; при желании
   переменные `MAX_PRICE`, `BANALI` и т. д. (как в `.env.example`).
3. `git clone https://huggingface.co/spaces/<user>/<space> ../listam-space` (пароль: токен HF с правом записи).
4. `scripts/sync_space.sh ../listam-space`, затем `cd ../listam-space && git add -A && git commit -m "Bot" && git push`.
5. Логи сборки и контейнера: Space → Logs. Ждите `playwright install chromium -> rc=0`, затем
   в Telegram придут «📌 baseline saved».
6. Пингер на `https://<user>-<space>.hf.space/health` раз в ~5 минут (GET и HEAD работают): без посетителей
   бесплатный Space засыпает через 48 часов. У приватного Space нужен заголовок
   `Authorization: Bearer <токен HF>` (cron-job.org умеет кастомные заголовки бесплатно).

Ограничения: диска нет (состояние стирается при перезапуске, бот заново молча сохраняет базу и
пропускает то, что появилось за время простоя); `/maxprice` сбрасывается (меняйте `MAX_PRICE`);
если имя пакета из `packages.txt` не найдётся в образе Space, сборка упадёт и нужно поправить список по логу.

## Render (устарело для list.am)

`render.yaml` описывает бесплатный веб-сервис. banali.am на нём работает, но list.am блокируется
Cloudflare (лёгкий клиент с IP Render не проходит), поэтому для обоих сайтов используйте Space.
